# Branch Companion 0.4.6

ChatGPT Windows 桌面端的本地分支与书签助手。在原生划词菜单中创建分支或保存选区，跨聊天跳回原文；书签支持公式预览、搜索、重命名和本机外部跳转链接。

沿用本机原分支助手的连接架构。它是依赖客户端内部组件的本地原型，未修改客户端安装文件，不调用额外模型 API，也不会自动发送聊天消息。

## 使用

安装 Node.js 22 或更新版本，双击 **打开书签助手.cmd**。已连接的旧助手会先保存记录，再连接新版；客户端没有启动时，启动器尝试启动已安装的正常版客户端。

聊天客户端须提供本机调试连接；默认端口 19347。外部书签链接服务使用 19348，仅监听 127.0.0.1。助手关闭时，链接不可用。

详细操作和限制见 [书签使用说明](书签使用说明.md)，实际验证范围见 [书签验证记录](书签验证记录.md)。

## 本版变化

- 在原生划词菜单添加书签；拖选过程中隐藏操作按钮，兼容分数和带方框的公式选区。
- 书签面板保留加粗、上下标和数学结构，过滤重复的公式辅助文本。
- 分支与书签上下排列，从入口位置展开；文件预览中避开“打开”、下载和分享工具栏。
- 定位高亮约 1 秒后消失，用户点击、滚动或键盘操作时立即清除。
- 独立文件保存、旧助手状态迁移和本机外部链接跳转。

## 开发检查

没有第三方运行依赖，也不需要安装依赖包。

```text
npm run check
npm test
```

自动测试覆盖记录校验、文件保存与恢复、请求来源校验和链接分发；真实客户端交互验证另见验证记录。

`branch-state*.json*`、`bookmark-state*.json*` 和备份包含私人聊天片段、位置标识及书签链接编号，已由 `.gitignore` 排除，不进入版本控制。
