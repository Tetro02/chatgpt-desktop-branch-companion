# GPT助手 0.5.0

ChatGPT Windows 桌面端的统一助手框架。目前内置 **分支** 和 **书签** 两个功能模块，后续功能继续在这个框架内开发，共用启动、客户端连接和模块生命周期。

沿用本机原分支助手的连接架构。它是依赖客户端内部组件的本地原型，未修改客户端安装文件，不调用额外模型 API，也不会自动发送聊天消息。

## 使用

安装 Node.js 22 或更新版本，双击 **打开GPT助手.cmd**。已连接的旧助手会先保存记录，再连接新版；客户端没有启动时，启动器尝试启动已安装的正常版客户端。旧版的“打开分支助手”和“打开书签助手”入口兼容保留，均连接同一个GPT助手。

仓库地址：[Tetro02/gpt-assistant](https://github.com/Tetro02/gpt-assistant)。也可使用英文入口 `launch.cmd`。

聊天客户端须提供本机调试连接；默认端口 19347。外部书签链接服务使用 19348，仅监听 127.0.0.1。助手关闭时，链接不可用。

详细操作和限制见 [GPT助手使用说明](GPT助手使用说明.md)，实际验证范围见 [验证记录](书签验证记录.md)。

分支工作方式可参考[已公开的历史使用示例](docs/分支使用示例.md)；其中截图为 0.3.3 界面。

## 框架与扩展

统一名称、版本和模块清单由 `assistant.config.cjs` 与 `package.json` 管理。`inject.cjs` 按模块清单加载代码、管理热更新，并通过 `window.__gptAssistant` 提供统一模块入口。当前模块为 `branches`（分支）与 `bookmarks`（书签）。

新功能作为模块加入同一清单，无需另起一套连接程序。开发约定见 [模块扩展指南](模块扩展指南.md)。历史源码文件名、存储键和目录名保留兼容，现有记录与链接可以继续使用。

## 本版变化

- 统一产品名称为“GPT助手”，新增统一启动入口和模块注册清单。

- 在原生划词菜单添加书签；拖选过程中隐藏操作按钮，兼容分数和带方框的公式选区。
- 书签面板保留加粗、上下标和数学结构，过滤重复的公式辅助文本。
- 分支与书签上下排列，从入口位置展开；文件预览中避开“打开”、下载和分享工具栏。
- 定位高亮约 1 秒后消失，用户点击、滚动或键盘操作时立即清除。
- 独立文件保存、旧助手状态迁移和本机外部链接跳转。

## 开发检查

没有第三方运行依赖，也不需要安装依赖包。

```text
npm run check
npm test
```

自动测试覆盖记录校验、文件保存与恢复、请求来源校验和链接分发；真实客户端交互验证另见验证记录。

`branch-state*.json*`、`bookmark-state*.json*` 和备份包含私人聊天片段、位置标识及书签链接编号，已由 `.gitignore` 排除，不进入版本控制。
