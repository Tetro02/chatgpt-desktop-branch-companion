# GPT助手 {{VERSION}}

Windows 版 ChatGPT 桌面端的统一助手，内置对话分支和原文书签，后续能力可继续作为模块扩展。

## 功能简介

- **对话分支**：选中文字后点击“添加到新的分支”，保留此前上下文；用树形列表查看分支与子分支，并回到来源原文。助手不会替你发送追问。
- **原文书签**：选中消息中的一行或一段，点击“添加书签”；在书签列表中搜索、重命名，并跨聊天跳回保存位置。
- **公式预览**：书签保留加粗、上下标和数学结构，减少公式辅助文本重复显示。
- **外部跳转**：复制本机书签链接，放进笔记或浏览器收藏夹；保持助手运行，打开链接即可定位原文。
- **统一界面**：分支与书签面板上下排列，避开文件预览工具栏；跳转高亮约一秒后消失。

## 开始使用

1. 准备 Windows 10/11、Node.js 22 或更新版本，以及正常安装的 ChatGPT 桌面客户端。
2. 完整解压 ZIP，保留 app 文件夹与启动入口的位置关系。
3. 双击 **打开GPT助手.cmd**，保持连接窗口运行。
4. 在回答里选中文字，松开鼠标后使用划词菜单中的分支或书签按钮。

若客户端已通过兼容的本机调试入口启动，助手会保存旧助手状态并重新连接。否则启动器会尝试启动正式版客户端；如果提示客户端已运行但没有兼容入口，请完整退出客户端后重试。

## 数据与升级

分支和书签保存在 app/branch-state.json 与 app/bookmark-state.json，并可能生成 .bak 备份。这些文件在首次使用后创建，包含私人原文及聊天标识，不要公开分享。

升级时先关闭旧助手的连接窗口，并备份上述记录。将旧目录的 branch-state.json、bookmark-state.json 复制到新包的 app/ 中，再启动新版。不要覆盖仍在运行中的记录文件。

助手关闭后，外部书签链接无法使用；链接仅适用于运行助手的这台电脑。本机连接端口为 19347，书签链接端口为 19348，请勿向外网开放。

## 当前范围

依赖桌面客户端内部界面，客户端更新后可能需要适配。原文变化或位置不能唯一确定时会提示失败；很长的历史可能需要先手动加载。并非所有 Work 内容、附件内部文字或公式局部选区都保证可建立书签。启动与交互不使用额外模型 API。

这是非官方项目，与 OpenAI 无隶属或认可关系。源码、开发文档与验证范围：[Tetro02/gpt-assistant](https://github.com/Tetro02/gpt-assistant)。
